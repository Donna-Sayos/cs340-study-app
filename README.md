# Study site
Plain HTML/CSS/JS, no build step. Netlify: drag this folder onto "Deploy manually", or connect a Git repo.
Add a lecture: copy a file in `lectures/`, change `n`, `title`, `cards`, `qs`, then add one `<script>` line in `index.html`.
Question format: `[question, [options], [indexes of correct options], explanation]`. Quiz length and exam length are `QUIZ_N` and `EXAM_N` at the top of `app.js`.
